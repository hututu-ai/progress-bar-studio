# Progress Bar Studio｜AI 动态进度条 Skill

> 上传视频与一张角色图，让 Codex 自动拆分章节、生成同一 IP 的行走动作，并交付可直接导入剪辑软件的透明进度条。

过去，一条章节进度条需要手工拆时间、画轨道、摆关键帧，再反复校准角色位置。现在，只需要完成五次明确确认，剩下的章节分析、角色处理、动画制作与透明度质检交给 Skill。

## 快速安装

```bash
git clone https://github.com/hututu-ai/progress-bar-studio.git
cd progress-bar-studio
cp -R skill/progress-bar-studio ~/.codex/skills/
```

重新打开 Codex 后，直接发送视频、角色图并描述需求：

```text
帮我给这个视频制作章节进度条。
使用我上传的角色，生成四帧逐帧行走版本；透明底，适配剪映。
```

也可以不使用角色：

```text
分析这个视频的章节，使用 S3 文字推进样式制作纯进度条。
主色使用 #E89AB3，导出透明 ProRes 4444 MOV。
```

## 核心能力

| 能力 | 说明 |
| --- | --- |
| 语义章节分析 | 根据视频语音和真实内容转折生成 4–7 个可编辑章节，不按时长机械平分 |
| 同一 IP 行走角色 | 支持不使用角色、单张轻动和固定四帧逐帧循环，保留角色外形、配色与标志性细节 |
| 四种内置样式 | S1 章节胶囊、S2 分段跑道、S3 文字推进、S4 标签分栏带 |
| 自定义参考图 | 上传自己喜欢的进度条，AI 提取轨道、节点、标签、填充和行走平面，重建成专属版本 |
| 自定义配色 | 支持色盘、参考图取色和 HEX，自动派生完整可编辑色组 |
| 五步确认 | 每一步先展示理解与证据，确认后才继续，减少误生成和重复消耗 |
| 透明交付 | 输出透明角色素材、动画预览和 ProRes 4444 进度条，并执行 Alpha 质检 |

自定义参考图属于**第四步的样式入口**，不会额外增加工作步骤。参考图只用于理解结构语言，不会直接放大截图冒充高清成品。

## 五步工作流

### 01｜上传素材

保留原文件不变，检查视频时长、画幅、帧率、音频、目标编辑器和输出位置。用户确认素材简报后才继续。

### 02｜生成或跳过角色

可选择纯进度条、单张轻动或四帧逐帧。使用角色时，Codex 会根据原图生成朝右行走版本，并检查透明通道、脚底基线与身份一致性。

### 03｜确认章节

从语音内容中识别真实转折点，生成时间戳、短章节名和划分理由。章节可编辑，确认后才进入视觉制作。

### 04｜选择样式与配色

从四种预设中选择，或上传有权使用的参考图进行结构重建。角色位置由样式规则自动决定，不再重复询问“角色放在哪里”。

### 05｜预览与导出

先检查真实视频叠加效果、字幕避让、行走贴轨、章节切换和多背景透明度。用户确认交付清单后再生成完整版。

## 输出内容

根据项目设置，Skill 可以交付：

- 透明角色 PNG；
- 四帧透明 PNG 序列、精灵图与动画 WebP；
- 章节、样式与决策记录 JSON；
- 3840 像素宽透明进度条；
- ProRes 4444 MOV 母版；
- 带原视频声音的轻量合成预览；
- 章节边界、多背景和 Alpha 通道质检图；
- 最终文件校验值与编辑器导入记录。

默认所说的“4K 进度条”指 **3840 像素宽的透明条带**，高度由样式决定，避免编码大量无用透明区域。

## 随 Skill 提供的工具

| 文件 | 用途 |
| --- | --- |
| `probe_video.sh` | 探测视频尺寸、帧率、时长、音频与磁盘空间 |
| `split_walk_cycle.py` | 拆分四帧透明精灵图，检查脚底基线并生成 WebP 预览与清单 |
| `make_multibg_preview.sh` | 在多种背景上检查透明角色边缘 |
| `verify_alpha_mov.sh` | 逐帧验证 ProRes 4444 的 Alpha 通道 |

运行完整媒体流程时，系统需要 `ffmpeg` / `ffprobe`；四帧拆分脚本需要 Python 3 与 Pillow。

## Skill 校验

```bash
python3 ~/.codex/skills/.system/skill-creator/scripts/quick_validate.py \
  skill/progress-bar-studio
```

透明成品不能只凭“文件生成成功”判断。完整验收还应核对编码、Alpha、帧数、章节边界、角色贴轨效果，以及目标剪辑软件的实际导入结果。

## 使用边界

- 参考图应由用户拥有或有权使用；
- 不保留参考图中的第三方角色、Logo、水印或专有图形；
- 未实际导入测试前，不宣称某款剪辑软件已经完全兼容；
- 仓库中的示例角色与插画仅用于演示，不代表向第三方授予复用权；
- 大尺寸透明动画可能占用较多磁盘空间，完整渲染前会先检查容量。

## 项目定位

Progress Bar Studio 是一个面向内容创作者、教师和运营人员的 Codex Skill，也是「AI 无限开发者创作大赛」参赛作品。它把重复的关键帧劳动压缩成一条清晰流程：**上传素材 → 逐步确认 → 透明交付**。

过去的工作流 VS 现在的工作流

过去要搭关键帧，
现在只需要上传视频

同一条章节进度条，手工制作要反复卡时间、调动画；现在由网页完成选择与确认，由 Codex Skill 负责高质量透明成片。

过去 · 手工制作

一条进度条，要拆成很多零碎操作

  • 听完整条视频，手动划分章节
  • 逐个计算时间点，搭建关键帧
  • 抠角色、做动画、反复调整位置
  • 视频一删改，时间轴和动画重新校准
现在 · 网页＋Skill 协作

上传一次，在一个工作台里完成

  • 本地提取音频，AI 识别语义转折与时间点
  • 角色可跳过，也可定制单张或四帧行走版
  • 四种预设可直接选，也能上传参考图定制
  • 透明素材网页导出，4K 母版交给 Codex
从“手动搭关键帧”变成“上传 → 五步确认 → 透明导出”
HUMAN-IN-THE-LOOP

每一步先给你看，
确认后才继续

Skill 不会一路埋头跑到成片。每一步都交付一个可检查结果，只问一个关键确认；需要修改时只回退受影响的步骤。

01
素材简报确认文件、视频参数、目标编辑器与输出规格
未确认：不转写、不生成
02
角色模式与身份确认无角色 / 单张 / 四帧，以及同一 IP 与脚底线
不满意：只重做角色
03
章节时间线确认时间点、章节名与每个语义转折依据
修改后：撤销样式与导出确认
04
样式与视觉适配确认预设 / 参考图、配色、行走平面与画面避让
修改后：只撤销导出确认
05
交付与完整渲染确认文件清单、尺寸、编码、空间与是否先测 15 秒
授权后：才开始完整编码
每次确认都会写入 decision-log.json；用户已经明确说过的选择会被记录，不重复追问。
